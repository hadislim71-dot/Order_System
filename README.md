This is a simple full stack web project that considers base customer accesses with admin accesses in a real life websites or E-commerce systems.
It's a basic level project, without frameworks, merges actors with one side (not admin side & customer side), and data are locally served.

Web Technologies used:
. HTML
. CSS
. Bootstrap
. JavaScript
. PHP
. MySQL
. Git
. GitHub

Software Tools:
. VS Code (Source Code Editor)
. XAMPP (Local Web Server Solution Stack)
